# Projeto G2 — Análise da Qualidade do Ar no Brasil

## Descrição

Este projeto foi desenvolvido para a disciplina **Linguagem de Programação — Análise e Visualização de Dados com Python**.

O objetivo é realizar uma análise exploratória sobre indicadores de qualidade do ar em cidades brasileiras, utilizando técnicas de tratamento de dados, geração de KPIs, visualizações gráficas e desenvolvimento de dashboard interativo.

---

## Objetivos

* Realizar análise exploratória de dados;
* Limpar e preparar a base de dados;
* Criar indicadores (KPIs);
* Construir gráficos para interpretação dos dados;
* Desenvolver dashboard interativo utilizando Streamlit;
* Publicar o projeto online.

---

